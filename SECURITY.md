# Security

These are desktop apps and small tools maintained by one person. If you find a security problem in any of them, please do not open a public issue with the details.

- Use **Report a vulnerability** on the repository's *Security* tab. The report stays private until it is fixed.
- If that button is not there, open an ordinary issue that only says you have found a security problem, without the details, and I will get in touch.

Please include the project, the version or commit, what can happen and how to reproduce it. Fixes go into the next release, and the release notes say what was fixed once people have had a chance to update.

Only the latest release of each project is supported.
