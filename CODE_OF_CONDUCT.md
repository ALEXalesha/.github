# Code of conduct

Be kind and assume good intent. Everyone who opens an issue or a pull request is trying to make the program better, including when English or Russian is not their first language.

Not welcome here: insults, harassment, personal attacks, and posting anyone's private information. Comments like that are deleted, and repeated behaviour leads to a block.

If someone makes you uncomfortable in these repositories, report it through GitHub (*Report content* on the comment) or open an issue asking for contact, and it will be handled privately.
